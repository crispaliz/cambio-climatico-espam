# practicas/comun — cuadernos comunes a las dos carreras

Obtención y preparación de datos, idénticas para Ingeniería Ambiental e Ingeniería en Riesgos de Desastres. Todo lo que producen queda en `Mi unidad/CC_datos/<zona>/` y lo leen las prácticas de ambas carreras.

| Carpeta | Cuadernos | Estado |
|---|---|---|
| [reanalisis](reanalisis/) | `CR01_descarga_reanalisis` → `CR02_series_zona` | Disponible |
| [estaciones](estaciones/) | Formato común de datos de estación (`plantilla_estacion.csv`) | Disponible |
| [bitacora](bitacora/) | Bitácora del evento El Niño 2026–2027 (`bitacora_el_nino.csv`), anexo del capítulo 1 en las dos carreras | Disponible |
| satelite | `CS…`: CHIRPS, IMERG, PERSIANN, MSWEP | Próximamente |
| modelos | `CM…`: salidas históricas de CMIP6 | Próximamente |
| escenarios | `CE…`: proyecciones SSP regionalizadas y con corrección de sesgo | Próximamente |

La zona (provincia o cantón) se elige igual en todos los cuadernos, con el formulario de la celda 1.
